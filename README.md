A tool to adapt your curriculum to any position

## 🧪 Tests y Coverage

Para ejecutar los tests y generar automáticamente los badges:

```bash
uv run pytest
```

Los badges se generarán automáticamente en `badges/tests.svg` y `badges/coverage.svg`.

### Reportes generados

- **HTML Coverage**: `htmlcov/index.html`
- **XML Coverage**: `coverage.xml`
- **JUnit XML**: `test-results.xml`
- **Badges**: `badges/tests.svg`, `badges/coverage.svg`
